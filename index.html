Bem-vindo à Documentação Lua

Lua é uma linguagem de programação leve, eficiente e poderosa, projetada para ser incorporada em outras aplicações. Com uma sintaxe simples e poderosa, é amplamente usada em games, scripts, e aplicações que precisam de extensibilidade.

Por que Lua?

  • Leve: Interpretador pequeno e rápido
  • Dinâmica: Tipagem dinâmica com flexibilidade
  • Poderosa: First-class functions, closures e coroutines
  • Extensível: Fácil integração com C/C++
  • Portável: Roda em praticamente qualquer plataforma
📌 Nota: Esta documentação cobre Lua 5.1, o padrão mais usado. Conceitos podem variar em versões posteriores.

Tipos de Dados

Lua tem 8 tipos de dados básicos:

1. Nil

Representa a ausência de valor. Variáveis não inicializadas são nil.

local x
print(x)  -- Output: nil

local y = nil
print(type(y))  -- Output: nil

2. Boolean

Valores verdadeiro e falso.

local ativo = true
local desativo = false

if ativo then
    print("Está ativo")
end
⚠️ Importante: Em Lua, nil e false são "falsy", mas 0 e strings vazias são "truthy"!

3. Number

Números inteiros ou ponto flutuante. Lua trata todos como números.

local inteiro = 42
local decimal = 3.14
local negativo = -100
local cientifico = 1.5e3  -- 1500

print(type(inteiro))  -- Output: number

4. String

Sequências de caracteres. Imutáveis.

local texto = "Olá Lua"
local entre_aspas = 'Lua é ótima'
local multilinha = [[
    Texto que ocupa
    várias linhas
]]

-- Concatenação
local mensagem = "Hello" .. " " .. "Lua"
print(mensagem)  -- Output: Hello Lua

5. Table

A estrutura de dados mais importante em Lua. Arrays, maps e objetos.

-- Array
local numeros = {1, 2, 3, 4, 5}

-- Map/Dicionário
local pessoa = {
    nome = "João",
    idade = 30,
    ativo = true
}

-- Acesso
print(numeros[1])       -- Output: 1
print(pessoa.nome)      -- Output: João
print(pessoa["idade"])  -- Output: 30

6. Function

Funções são valores de primeira classe em Lua.

local minhaFuncao = function(x)
    return x * 2
end

print(minhaFuncao(5))  -- Output: 10

7. Userdata

Dados C/C++ envolvidos para Lua. Normalmente usado em integração com C.

8. Thread

Coroutines (não threads do SO). Veremos mais adiante.

Variáveis e Escopo

Escopo Global vs Local

global = "Sou global"  -- Acessível em qualquer lugar

function minha_funcao()
    local local_var = "Sou local"  -- Só acessível nesta função
    print(global)      -- OK
    print(local_var)   -- OK
end

print(local_var)  -- Erro: nil (não existe fora da função)

Escopo em Blocos

Em Lua, variáveis locais têm escopo até o fim do bloco onde foram declaradas:

if true then
    local x = 10
    print(x)  -- Output: 10
end

print(x)  -- Output: nil

Shadowing

Você pode redeclarar variáveis em escopos internos:

local x = "global"

function teste()
    local x = "local"  -- Diferente do x global
    print(x)  -- Output: local
end

print(x)  -- Output: global
✅ Melhor Prática: Sempre use local por padrão. Variáveis globais devem ser evitadas a menos que absolutamente necessário.

Inicialização Múltipla

local a, b, c = 1, 2, 3
print(a, b, c)  -- Output: 1    2    3

local x, y = 10
print(x, y)  -- Output: 10    nil

local p, q, r = 1, 2, 3, 4
print(p, q, r)  -- Output: 1    2    3 (r ignora o 4)

Funções

Definição Básica

Funções em Lua podem ser definidas usando function ou como valores anônimos:

-- Forma 1: Nomeada
function saudacao(nome)
    return "Olá, " .. nome
end

-- Forma 2: Anônima/Lambda
local saudacao2 = function(nome)
    return "Olá, " .. nome
end

print(saudacao("João"))   -- Output: Olá, João
print(saudacao2("Maria")) -- Output: Olá, Maria

Retornos Múltiplos

Lua permite retornar múltiplos valores:

function obter_dados()
    return "João", 30, true
end

local nome, idade, ativo = obter_dados()
print(nome, idade, ativo)  -- Output: João    30    true

-- Ignorar valores
local nome = obter_dados()
print(nome)  -- Output: João

Funções Aninhadas

function externa()
    local valor = 10
    
    function interna()
        return valor * 2
    end
    
    return interna()
end

print(externa())  -- Output: 20

Funções como Parâmetros

function aplicar_operacao(a, b, operacao)
    return operacao(a, b)
end

function somar(x, y)
    return x + y
end

function multiplicar(x, y)
    return x * y
end

print(aplicar_operacao(5, 3, somar))       -- Output: 8
print(aplicar_operacao(5, 3, multiplicar)) -- Output: 15

Funções que Retornam Funções

function criar_multiplicador(fator)
    return function(numero)
        return numero * fator
    end
end

local multiplicar_por_2 = criar_multiplicador(2)
local multiplicar_por_5 = criar_multiplicador(5)

print(multiplicar_por_2(10))  -- Output: 20
print(multiplicar_por_5(10))  -- Output: 50
💡 Dica: Em Lua, local function nome() end é equivalente a local nome = function() end, mas é mais legível.

Argumentos e Retornos

Argumentos Opcionais

function saudacao(nome, titulo)
    titulo = titulo or "Sr."
    return titulo .. " " .. nome
end

print(saudacao("João"))         -- Output: Sr. João
print(saudacao("Maria", "Dra.")) -- Output: Dra. Maria

Argumentos com Valores Padrão

function criar_usuario(nome, age, ativo)
    age = age or 18
    ativo = ativo or true
    
    return {
        nome = nome,
        age = age,
        ativo = ativo
    }
end

local user1 = criar_usuario("João")
local user2 = criar_usuario("Maria", 25, false)

print(user1.age)    -- Output: 18
print(user2.ativo)  -- Output: false

Retorno Condicional

function dividir(a, b)
    if b == 0 then
        return nil, "Erro: divisão por zero"
    end
    return a / b, nil
end

local resultado, erro = dividir(10, 2)
if erro then
    print("Erro: " .. erro)
else
    print("Resultado: " .. resultado)
end

Descarte de Retornos Não Utilizados

function tres_valores()
    return 1, 2, 3
end

-- Pega apenas o primeiro
local primeiro = tres_valores()
print(primeiro)  -- Output: 1

-- Ignora alguns
local a, _, c = tres_valores()
print(a, c)  -- Output: 1    3

Varargs (...) - Argumentos Variáveis

O que são Varargs?

Varargs (variadic arguments) permitem que uma função aceite um número indefinido de argumentos:

function somar(...)
    local total = 0
    local args = {...}  -- Converte ... em tabela
    
    for i = 1, #args do
        total = total + args[i]
    end
    
    return total
end

print(somar(1, 2, 3))         -- Output: 6
print(somar(1, 2, 3, 4, 5))   -- Output: 15

Acessar Varargs Diretamente

function imprimir_todos(...)
    -- select(n, ...) retorna o n-ésimo argumento
    -- select('#', ...) retorna o número total de argumentos
    
    local count = select('#', ...)
    print("Total de argumentos: " .. count)
    
    for i = 1, count do
        print(i .. ": " .. select(i, ...))
    end
end

imprimir_todos("a", "b", "c")

Misturar Parâmetros Nomeados e Varargs

function criar_lista(titulo, ...)
    local items = {...}
    
    print("Lista: " .. titulo)
    for i, item in ipairs(items) do
        print("  " .. i .. ". " .. item)
    end
end

criar_lista("Compras", "Leite", "Pão", "Ovos", "Queijo")

Passar Varargs para Outra Função

function wrapper(...)
    -- Passa os argumentos adiante
    return original_function(...)
end

function original_function(a, b, c)
    return a + b + c
end

print(wrapper(1, 2, 3))  -- Output: 6
Exemplo Prático: Concatenar com Separador
function concatenar_com_separador(separador, ...)
    local args = {...}
    local resultado = ""
    
    for i = 1, #args do
        resultado = resultado .. tostring(args[i])
        if i < #args then
            resultado = resultado .. separador
        end
    end
    
    return resultado
end

print(concatenar_com_separador(", ", "a", "b", "c", "d"))
-- Output: a, b, c, d
a, b, c, d

Closures

O que são Closures?

Um closure é uma função que "captura" variáveis do escopo onde foi definida, mesmo após a função externa terminar:

function criar_contador()
    local contagem = 0  -- Variável capturada
    
    return function()
        contagem = contagem + 1
        return contagem
    end
end

local contador = criar_contador()
print(contador())  -- Output: 1
print(contador())  -- Output: 2
print(contador())  -- Output: 3

Múltiplas Closures Independentes

function criar_contador()
    local contagem = 0
    return function()
        contagem = contagem + 1
        return contagem
    end
end

local contador1 = criar_contador()
local contador2 = criar_contador()

print(contador1())  -- Output: 1
print(contador1())  -- Output: 2
print(contador2())  -- Output: 1  (Independente!)
print(contador1())  -- Output: 3

Closures com Múltiplas Variáveis

function criar_pessoa(nome)
    local historico = {}
    
    return {
        registrar = function(acao)
            table.insert(historico, acao)
        end,
        obter_historico = function()
            return historico
        end,
        obter_nome = function()
            return nome
        end
    }
end

local pessoa = criar_pessoa("João")
pessoa.registrar("Acordou")
pessoa.registrar("Comeu")
pessoa.registrar("Dormiu")

for _, acao in ipairs(pessoa.obter_historico()) do
    print(pessoa.obter_nome() .. " " .. acao)
end
💡 Caso de Uso: Closures são perfeitos para criar dados privados e métodos, simulando "encapsulamento" em linguagens orientadas a objetos.

Metatables e Metamétodos

O que são Metatables?

Metatables permitem customizar o comportamento de tables. Elas definem como operações e operadores funcionam em uma table.

Definir uma Metatable

local tabela = {a = 1, b = 2}
local metatable = {}

setmetatable(tabela, metatable)
print(getmetatable(tabela))  -- Output: table: 0x...

-- Também pode ser feito em uma linha
local tabela = setmetatable({a = 1}, {})

Metamétodo __index

Chamado quando você tenta acessar uma chave que não existe:

local tabela = {a = 1}
local meta = {
    __index = function(t, chave)
        return "Chave '" .. chave .. "' não encontrada"
    end
}
setmetatable(tabela, meta)

print(tabela.a)    -- Output: 1
print(tabela.xyz)  -- Output: Chave 'xyz' não encontrada

Metamétodo __newindex

Chamado quando você tenta atribuir uma chave:

local tabela = {}
local meta = {
    __newindex = function(t, chave, valor)
        print("Tentando atribuir " .. chave .. " = " .. valor)
        rawset(t, chave, valor)  -- rawset ignora metamétodos
    end
}
setmetatable(tabela, meta)

tabela.nome = "João"  -- Output: Tentando atribuir nome = João
print(tabela.nome)     -- Output: João

Metamétodo __add

Permite usar o operador + com tables:

local vetor1 = {x = 1, y = 2}
local vetor2 = {x = 3, y = 4}

local meta = {
    __add = function(v1, v2)
        return {
            x = v1.x + v2.x,
            y = v1.y + v2.y
        }
    end
}

setmetatable(vetor1, meta)
setmetatable(vetor2, meta)

local vetor3 = vetor1 + vetor2
print(vetor3.x, vetor3.y)  -- Output: 4    6

Metamétodo __call

Permite chamar uma table como função:

local contador = {valor = 0}
local meta = {
    __call = function(self, quantidade)
        quantidade = quantidade or 1
        self.valor = self.valor + quantidade
        return self.valor
    end
}
setmetatable(contador, meta)

print(contador())       -- Output: 1
print(contador(5))      -- Output: 6
print(contador(3))      -- Output: 9

Metamétodo __tostring

Customiza como a table é convertida para string:

local pessoa = {nome = "João", idade = 30}
local meta = {
    __tostring = function(self)
        return self.nome .. " (" .. self.idade .. " anos)"
    end
}
setmetatable(pessoa, meta)

print(pessoa)  -- Output: João (30 anos)
print("Pessoa: " .. pessoa)  -- Output: Pessoa: João (30 anos)

Metamétodo __lt e __le

Customiza comparações:

local pessoa1 = {nome = "João", idade = 30}
local pessoa2 = {nome = "Maria", idade = 25}

local meta = {
    __lt = function(a, b)
        return a.idade < b.idade
    end
}

setmetatable(pessoa1, meta)
setmetatable(pessoa2, meta)

if pessoa2 < pessoa1 then
    print("Maria é mais jovem")
end

Coroutines (Threads Leves)

O que são Coroutines?

Coroutines são "threads leves" que permitem suspender e retomar execução. Não são threads reais do SO - Lua as controla inteiramente.

Criar e Retomar

-- Criar coroutine
local co = coroutine.create(function()
    print("1")
    coroutine.yield()  -- Suspende aqui
    print("2")
    coroutine.yield()
    print("3")
end)

-- Retomar execução
coroutine.resume(co)  -- Output: 1
coroutine.resume(co)  -- Output: 2
coroutine.resume(co)  -- Output: 3

Coroutine.wrap

Alternativa mais simples a create e resume:

local funcao = coroutine.wrap(function()
    print("A")
    coroutine.yield()
    print("B")
    return "Resultado"
end)

print(funcao())  -- Output: A
print(funcao())  -- Output: B, Resultado

Passar Valores Entre Coroutines

local co = coroutine.create(function()
    local valor = coroutine.yield()  -- Recebe valor
    print("Recebi: " .. valor)
    return "Resposta"
end)

local _, resultado = coroutine.resume(co, "Olá")  -- Envia valor
coroutine.resume(co)
-- Output: Recebi: Olá

Status de Coroutines

local co = coroutine.create(function()
    coroutine.yield()
end)

print(coroutine.status(co))  -- Output: suspended

coroutine.resume(co)
print(coroutine.status(co))  -- Output: suspended

coroutine.resume(co)
print(coroutine.status(co))  -- Output: dead

Caso de Uso: Iterator Customizado

function contador_customizado(inicio, fim)
    return coroutine.wrap(function()
        for i = inicio, fim do
            coroutine.yield(i)
        end
    end)
end

for numero in contador_customizado(1, 5) do
    print(numero)
end
-- Output: 1 2 3 4 5
💡 Diferença Importante: Coroutines não são paralelismo. Uma coroutine só executa quando explicitamente retomada. Úteis para manter estado entre iterações.

Modules

O que são Modules?

Modules permitem organizar código em arquivos separados e reutilizáveis. São a forma de modularizar projetos Lua.

Criar um Module Simples

Arquivo: matematica.lua

-- matematica.lua
local M = {}  -- Table do módulo

function M.somar(a, b)
    return a + b
end

function M.subtrair(a, b)
    return a - b
end

function M.multiplicar(a, b)
    return a * b
end

return M  -- Retorna o módulo

Usar um Module

Arquivo: main.lua

-- main.lua
local mat = require("matematica")

print(mat.somar(10, 5))       -- Output: 15
print(mat.subtrair(10, 5))    -- Output: 5
print(mat.multiplicar(10, 5)) -- Output: 50

Módulo com Dados Privados

Arquivo: contador.lua

-- contador.lua
local M = {}
local contagem = 0  -- Privado (não é retornado)

function M.incrementar()
    contagem = contagem + 1
    return contagem
end

function M.obter()
    return contagem
end

function M.resetar()
    contagem = 0
end

return M

Módulos Hierarchicos

Estrutura de diretório:

projeto/
├── main.lua
└── lib/
    ├── utils.lua
    └── dados.lua

Arquivo: lib/utils.lua

local M = {}

function M.formatarmensagem(texto)
    return ">>> " .. texto
end

return M

Arquivo: main.lua

local utils = require("lib.utils")
print(utils.formatarmensagem("Olá"))
-- Output: >>> Olá

require com LUA_PATH

O Lua procura modules no LUA_PATH. Para adicionar diretórios:

-- No início de main.lua
package.path = package.path .. ";./lib/?.lua"

local utils = require("utils")  -- Procura em ./lib/utils.lua

Verificar se Module está Carregado

if package.loaded["meumodulo"] then
    print("Módulo já foi carregado")
else
    print("Primeira vez carregando")
    require("meumodulo")
end
✅ Padrão Comum: No Lua, é comum usar require uma única vez e guardar a referência em uma variável local.

Environment e Escopo Global

O que é Environment?

Environment é a table que contém todas as variáveis globais. Você pode inspecionar e modificá-la programaticamente.

Acessar o Environment Global

-- _G é a table de variáveis globais
_G.minhaVariavel = 10
print(minhaVariavel)  -- Output: 10

-- Verificar se existe
if _G.variavel then
    print("Existe")
else
    print("Não existe")
end

Listar Variáveis Globais

for nome, valor in pairs(_G) do
    if type(valor) ~= "function" then
        print(nome .. " = " .. tostring(valor))
    end
end

Environment de Função

function minhaFuncao()
    local env = getfenv()  -- Obter ambiente da função
    print(type(env))  -- Output: table
end

minhaFuncao()

Mudar o Environment de uma Função

local novo_env = {print = print}  -- Novo ambiente

function original()
    print("Olá")
end

setfenv(original, novo_env)  -- Muda para novo_env
original()  -- Output: Olá

-- Agora original não tem acesso ao ambiente global original

Biblioteca de Funções Básicas

type()

Retorna o tipo de um valor:

print(type(5))           -- Output: number
print(type("lua"))       -- Output: string
print(type(true))        -- Output: boolean
print(type(nil))         -- Output: nil
print(type({}))          -- Output: table
print(type(print))       -- Output: function

tostring() e tonumber()

print(tostring(42))      -- Output: 42 (como string)
print(tostring(true))    -- Output: true

print(tonumber("42"))    -- Output: 42
print(tonumber("3.14"))  -- Output: 3.14
print(tonumber("abc"))   -- Output: nil

assert()

Verifica uma condição e lança erro se for falsa:

local valor = 10

assert(valor > 0, "Valor deve ser positivo")
print("OK")

-- Isto causaria erro:
-- assert(valor < 0, "Erro: valor não pode ser negativo")

error()

Lança um erro:

function dividir(a, b)
    if b == 0 then
        error("Divisão por zero!")
    end
    return a / b
end

local status, resultado = pcall(dividir, 10, 0)
if not status then
    print("Erro capturado: " .. resultado)
end

pcall() - Protected Call

Executa uma função protegida contra erros:

function funcao_com_risco()
    return 10 / 0  -- Erro
end

local sucesso, resultado = pcall(funcao_com_risco)
if sucesso then
    print(resultado)
else
    print("Erro: " .. resultado)
end

pairs() e ipairs()

local tabela = {a = 1, b = 2, c = 3}

-- pairs: itera sobre todos os elementos
for chave, valor in pairs(tabela) do
    print(chave .. " = " .. valor)
end

-- ipairs: itera apenas sobre índices numéricos em sequência
local numeros = {10, 20, 30}
for indice, valor in ipairs(numeros) do
    print(indice .. ": " .. valor)
end

next()

Retorna próximo par chave-valor:

local tabela = {a = 1, b = 2, c = 3}
local chave, valor = next(tabela)
print(chave, valor)  -- Output: a    1 (ou outro par)

select()

Lint, Style e Boas Práticas

O que é Lint?

Linting é verificar código em busca de erros, inconsistências e problemas de estilo antes da execução. Em Lua, ferramentas populares incluem Luacheck.

Instalar Luacheck

-- Via luarocks
luarocks install luacheck

-- Verificar arquivo
luacheck arquivo.lua

Erros Comuns Detectados por Lint

Erro Descrição Solução
Variável não usada local x = 10 -- x nunca é usado Remover ou usar a variável
Variável indefinida print(x) -- x nunca foi definido Declarar a variável com local
Variável global não intencional x = 10 -- sem local Usar local x = 10
Parâmetro não usado function f(x) print("Oi") end Usar o parâmetro ou renomear para _

Exemplo: Código com Problemas

-- ❌ Problemas
resultado = 5  -- Variável global não intencional
local x = 10   -- Variável não usada
function processar(dados)
    return 42
end

-- ✅ Corrigido
local resultado = 5
local x = 10
print(x)  -- Usar a variável
function processar(_)  -- Ignorar parâmetro
    return 42
end

Boas Práticas de Estilo

1. Use local por padrão

-- ❌ Ruim
x = 10
y = 20

-- ✅ Bom
local x = 10
local y = 20

2. Nomes descritivos

-- ❌ Ruim
local a = 5
local b = "João"

-- ✅ Bom
local idade = 5
local nome = "João"

3. Indentação consistente

-- ❌ Ruim
function teste()
  local x = 10
    if x > 5 then
    print("ok")
      end
end

-- ✅ Bom
function teste()
    local x = 10
    if x > 5 then
        print("ok")
    end
end

4. Evite callbacks profundos (Callback Hell)

-- ❌ Ruim (Callback Hell)
processarDados(function(resultado1)
    processarMais(resultado1, function(resultado2)
        processarAinda(resultado2, function(resultado3)
            print(resultado3)
        end)
    end)
end)

-- ✅ Bom (Separar em funções)
local function processar1(resultado1)
    processarMais(resultado1, processar2)
end

local function processar2(resultado2)
    processarAinda(resultado2, processar3)
end

local function processar3(resultado3)
    print(resultado3)
end

processarDados(processar1)

5. Tratamento de Erros

-- ❌ Ruim
local arquivo = io.open("dados.txt", "r")
local conteudo = arquivo:read("*a")
arquivo:close()

-- ✅ Bom
local arquivo = io.open("dados.txt", "r")
if not arquivo then
    print("Erro: arquivo não encontrado")
    return
end
local conteudo = arquivo:read("*a")
arquivo:close()

6. Documentação de Código

--[[
    Função: calcular_media
    Descrição: Calcula a média aritmética de uma lista de números
    Parâmetros:
        - numeros (table): Lista de números
    Retorno:
        - number: A média dos números
    Exemplo:
        local media = calcular_media({1, 2, 3, 4, 5})
        print(media) -- 3
]]
local function calcular_media(numeros)
    local soma = 0
    for _, valor in ipairs(numeros) do
        soma = soma + valor
    end
    return soma / #numeros
end
